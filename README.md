# Análisis de Series Temporales del Metro de Medellín

## Descripción del proyecto

Este proyecto consiste en un análisis de series temporales relacionado con las lineas del Metro de Medellín, desarrollado como parte de mi formación en Ciencia de Datos.

## Objetivo

Explorar los datos a través de técnicas de análisis temporal y visualización para identificar patrones, tendencias y comportamientos relevantes en la información estudiada.

## Herramientas utilizadas

- **R:** procesamiento y análisis estadístico.
- **R Markdown:** integración de código, resultados y explicaciones.
- **HTML:** presentación del informe final.
- **Visualización de datos:** representación gráfica de los resultados.

## Contenido del repositorio

- `Taller-final-series-de-tiempo.html`: informe del proyecto con los resultados y las visualizaciones generadas.
